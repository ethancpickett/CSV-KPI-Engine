# CSV-KPI-Engine
Multi-Tier Full-Stack Financial KPI Engine featuring*:
•	A structured architecture (backend/app/...)
•	Database persistence with SQLAlchemy and SQLite
•	Automated data parsing and financial ratio computations using Pandas (processor.py)
•	Historical Trend Line
•	Portfolio statistical aggregation (aggregator.py)
•	User Authenication
•	A live asynchronous API layer with FastAPI and Swagger documentation
